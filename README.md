# Food Guardian

Web application to reduce food waste by tracking expiration dates, listing inventory, and suggesting meal ideas.

## Goals

- Track food inventory
- Monitor expiration dates
- Reduce food waste
- Save MONEY
- Learn modern backend and cloud tech

## Tech Stack (the plan for now)

- Python
- FastAPI
- SQLite or PostgreSQL
- Docker
- Azure
- Terraform
- GitHub Actions
- Kubernetes
